## 需求背景

项目当前模型展示能力基于 raylib 6.0 的内置 cgltf, 支持 glTF/GLB 模型与骨骼动画。现需要加载角色模型并完成「模型 + 动画 + 贴图」的完整展示链路:

- 模型: `assets/models/body/MaleBody.glb`(glTF 2.0 二进制, 带骨骼蒙皮的角色网格)
- 贴图: `assets/texture/body/MaleBody01.png`

需要验证并落地的能力包括: 模型加载与展示、骨骼动画加载与播放、贴图加载与动态绑定。

## 需求目标

1. 在世界原点添加/保留网格参考平面, 模型加载后居中(落在网格中心)。
2. 移除现有默认加载的 `assets/models/cartoon_man.glb`, 将其从项目中删除。
3. 重构模型加载为「模型加载器」模块, 暴露统一接口, 可加载 `glb` 等格式, 并支持**动态贴图绑定**(不写死单张贴图)。
4. 支持骨骼动画的加载与播放(动画选择 / 播放暂停 / 循环 / 速度)。

## 设计方案

### 1. 资产目录结构

模型与贴图统一纳入 `assets/`, 按 `models` 与 `texture` 两个目录各建 `body` 子目录:

```text
assets/
├── models/
│   └── body/
│       └── MaleBody.glb
└── texture/
    └── body/
        └── MaleBody01.png
```

### 2. 模型加载器模块设计(功能化、模块化)

在 `core/model/model_loader.{h,cpp}` 的 `ModelScene` 类上扩展, 保持对外统一接口不变, 并新增**动态贴图绑定**能力:

- **统一入口**: `ModelScene::load(path, &error)` 按扩展名分派:
  - raylib 原生格式(`.glb / .gltf / .obj / .iqm / .vox / .m3d`)→ `LoadModel` + `LoadModelAnimations` 路径(含动画管线)。
  - 后续如需支持其它格式, 可在此处新增后端, 接口无需变动。
- **动态贴图绑定**(新增, 满足「不写死单张贴图」):
  - 新增枚举 `MaterialMapType`(对应 raylib `MaterialMapIndex`: 基础色 / 法线 / 金属度 / 粗糙度 / 遮蔽 / 自发光)。
  - 新增接口 `ModelScene::applyTexture(MaterialMapType mapType, const std::string& path, std::string* error)`: 内部用 raylib `LoadTexture` 加载贴图, 通过 `SetMaterialTexture` 绑定到模型所有材质的对应贴图槽; 路径由调用方传入, 实现「加载时加载指定路径的贴图」。
- **动画播放**: 复用现有动画推进逻辑(`UpdateModelAnimation`, 60fps 基准), 支持动画选择 / 播放暂停 / 循环 / 速度。

### 3. 网格平面与模型居中

- 主循环 3D 视口保留 `DrawGrid(20, 1.0f)`, 作为世界原点处的网格参考平面。
- 模型默认 `Transform.position = {0,0,0}`。加载成功后按模型包围盒计算底面, 自动将模型平移至脚底贴地、水平居中(原点位于包围盒底部中心), 复用现有 `fitCameraToModel` 设置默认相机。

### 4. 移除默认模型

- 删除 `assets/models/cartoon_man.glb`。
- `core/main.cpp` 中 `kDefaultModelPath` 由 `cartoon_man.glb` 改为 `assets/models/body/MaleBody.glb`, 并新增默认贴图路径 `assets/texture/body/MaleBody01.png` 用于加载后动态绑定。
- ImGui 面板新增「贴图路径 + 应用贴图」, 支持运行时换贴图。
- `docs/20260929-01-模型动画加载器.md` 中关于该 GLB 资产的描述仅作历史记录, 不改动。

### 5. 构建与文档变更

- 运行时**无新增依赖**, `vcpkg.json` / 顶层 `CMakeLists.txt` 不变。
- `core/CMakeLists.txt` 本次仅改 `main.cpp` 与 `model_loader`, 无新增源文件。
- 更新 `docs/项目架构文档.md`: 目录结构(`assets/models/body`、`assets/texture/body`)、模块设计(`ModelScene` 新增动态贴图绑定)。

### 6. 验证方式

- 重新构建并运行:
  - 日志输出 `.glb` 加载成功(网格/顶点/三角形/材质/动画数量);
  - 3D 视口原点网格平面上居中显示带贴图(`MaleBody01.png`)的角色模型;
  - 动画控制可用(动画数量 > 0, 可播放/暂停/循环/调速);
  - 确认原 `cartoon_man.glb` 已从项目移除。

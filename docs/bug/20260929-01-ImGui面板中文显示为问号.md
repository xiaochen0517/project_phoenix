# 20260929-01 ImGui 面板中文显示为问号

> 状态: 已修复 (2026-09-30)
>
> 日期: 2026-09-29
>
> 关联需求: [20260929-01 模型动画加载器](../demand/20260929-01-模型动画加载器.md)

## 漏洞现象

ImGui 面板中的中文标签(「模型」「相机」「路径」「加载模型」等)全部渲染为 `?`, 中文无法正常显示。

## 漏洞原因

ImGui 默认字体 `ProggyClean` 为位图字体, 仅含 ASCII/Latin 字形, 不含 CJK 字形。`rlImGuiSetup(true)` 内部 `rlImGuiBeginInitImGui()` 仅调用 `io.Fonts->AddFontDefault()`, 未加载任何中文字体, 因此所有中文标签渲染为 `?`。

## 修复方案

1. 将 `core/main.cpp` 中的 `rlImGuiSetup(true)` 替换为三步高级初始化, 在字体图集构建前加载 CJK 字体:
   - `rlImGuiBeginInitImGui()`(创建上下文并添加默认字体)
   - `ImGui::StyleColorsDark()`
   - 加载中文字体并以 `MergeMode` 合并进默认字体
   - `rlImGuiEndInitImGui()`(合并 FontAwesome 图标、初始化鼠标光标与后端)
2. 字体来源: 优先加载 `C:/Windows/Fonts/msyh.ttc`(微软雅黑), 缺失时回退 `C:/Windows/Fonts/simhei.ttf`(黑体); 均不存在则记录 `app_log` warning 并保持默认字体(中文仍显示 `?` 但不崩溃)。
3. 字表范围: 使用 `io.Fonts->GetGlyphRangesChineseFull()`(全量 CJK, 保证覆盖); 如需降低显存/图集占用可改用 `GetGlyphRangesChineseSimplifiedCommon()`。
4. 合并字体 `SizePixels` 与默认字体保持一致(13), 避免 ASCII 与中文字形大小错位。

## 验证结果 (2026-09-30)

已确认修复。加载微软雅黑后 ImGui 面板中文标签正常显示, 不再出现 `?`。

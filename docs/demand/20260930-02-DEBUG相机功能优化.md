## 需求背景

当前项目的 3D 视口相机只提供两种操作方式:

- **参数直调**: ImGui 中直接编辑 `位置 / 目标点 / Up / FOV / 投影方式`, 无法流畅地"边走边看"。
- **鼠标环绕控制**: `UpdateCamera(CAMERA_ORBITAL)`, 只能绕目标点旋转 + 滚轮缩放, 无法自由移动位置, 且不能俯仰到任意角度。

在调试角色模型 / 场景时, 经常需要像 Unity / Unreal 等游戏引擎编辑器一样, 自由地在场景中飞行、贴近观察模型局部细节, 而现有相机无法满足这种深度 debug 操作。因此需要新增一个「编辑器风格手动飞行相机」。

## 需求目标

1. 在 ImGui 中新增一个「手动操作」开关, 打开后即可用鼠标键盘直接操控相机。
2. 移动: `W/A/S/D` 前后左右(前后以当前视角朝向为准), `空格` 上升, `Ctrl` 下降。
3. 视角转动: 按住鼠标右键时隐藏(捕获)鼠标, 移动鼠标调整视角(偏航 + 俯仰)。
4. 配置项: ImGui 中可配置「移动速度」和「旋转速度」。
5. 与现有「鼠标环绕控制」互斥, 两种模式不能同时生效, 避免相机状态冲突。

## 设计方案

### 1. 交互方案

| 输入 | 行为 |
|---|---|
| `W` / `S` | 沿当前视角朝向 前进 / 后退(含垂直分量, 即低头按 W 会向下走) |
| `A` / `D` | 沿相机右方向 左移 / 右移(始终水平) |
| `空格` | 上升(沿相机 up, 默认即世界 +Y) |
| `Ctrl`(左) | 下降 |
| 按住右键 + 移动鼠标 | 偏航(Yaw)+ 俯仰(Pitch)旋转视角, 俯仰锁定在 ±90° 防止翻转 |
| 释放右键 | 恢复显示鼠标, 停止旋转 |

移动量按帧时间 `GetFrameTime()` 缩放, 保证帧率无关; 旋转量按鼠标像素增量计算, 天然帧率无关。

### 2. 状态变量(新增于 `core/main.cpp` 的 `main()` 中)

```cpp
bool manualControl = false;        // 手动操作开关
float cameraMoveSpeed = 5.0f;      // 移动速度 (单位/秒)
float cameraRotateSpeed = 0.003f;  // 旋转速度 (弧度/像素, 与 raylib CAMERA_MOUSE_MOVE_SENSITIVITY 一致)
```

### 3. 相机更新实现

新增匿名命名空间辅助函数 `updateManualCamera`(与现有 `resetCamera` / `fitCameraToModel` 同层):

```cpp
void updateManualCamera(Camera3D &camera, float moveSpeed, float rotateSpeed) {
    ImGuiIO &io = ImGui::GetIO();
    const float dist = moveSpeed * GetFrameTime();

    // 移动: 仅当键盘未被 ImGui 捕获(即未在文本框输入)时生效
    if (!io.WantCaptureKeyboard) {
        if (IsKeyDown(KEY_W))     CameraMoveForward(&camera,  dist, false);
        if (IsKeyDown(KEY_S))     CameraMoveForward(&camera, -dist, false);
        if (IsKeyDown(KEY_D))     CameraMoveRight(&camera,    dist, false);
        if (IsKeyDown(KEY_A))     CameraMoveRight(&camera,   -dist, false);
        if (IsKeyDown(KEY_SPACE)) CameraMoveUp(&camera,       dist);
        if (IsKeyDown(KEY_LEFT_CONTROL)) CameraMoveUp(&camera, -dist);
    }

    // 旋转: 右键按住时捕获鼠标并旋转 (仅当鼠标未被 ImGui 捕获时)
    const bool rotating = !io.WantCaptureMouse && IsMouseButtonDown(MOUSE_BUTTON_RIGHT);
    if (rotating) {
        DisableCursor();
        io.ConfigFlags |= ImGuiConfigFlags_NoMouseCursorChange;
        const Vector2 delta = GetMouseDelta();
        CameraYaw(&camera,   -delta.x * rotateSpeed, false);
        CameraPitch(&camera, -delta.y * rotateSpeed, true, false, false);
    } else {
        io.ConfigFlags &= ~ImGuiConfigFlags_NoMouseCursorChange;
        EnableCursor();
    }
}
```

**关键实现说明:**

- **复用 raylib 相机原语**: 上述 `CameraMoveForward / CameraMoveRight / CameraMoveUp / CameraYaw / CameraPitch` 均为 raylib 6.0 的内置相机函数, 定义在 `src/rcamera.h` 中(由 `rcore.c` 以 `RCAMERA_IMPLEMENTATION` 编入 raylib 静态库, 可直接链接)。其中 `CameraPitch(..., lockView=true, ...)` 自带俯仰 ±90° 锁定逻辑, 无需自行实现角度钳制。
- **需补充 include**: `raylib.h` 仅暴露 `UpdateCamera` / `UpdateCameraPro`, 上述粒度更细的相机函数未在 `raylib.h` 声明, 需在 `main.cpp` 中(位于 `#include "raylib.h"` 之后)追加 `#include "rcamera.h"`。该头文件与 `raylib.h` 同处 raylib 源码 `src/` 目录, 已在 raylib target 的 public include 路径中, 无需改动 CMake。
- **移动语义**: `CameraMoveForward(&camera, dist, false)` 的第三个参数 `moveInWorldPlane=false` 表示沿完整三维朝向(含垂直分量)移动, 与需求"前后以当前视角朝向为准"一致, 等价于 raylib `CAMERA_FREE` 模式的移动行为。
- **旋转语义**: `CameraYaw(..., rotateAroundTarget=false)` 绕相机 up 轴旋转 target, `CameraPitch(..., lockView=true, rotateAroundTarget=false, rotateUp=false)` 绕相机右轴旋转 target; `rotateUp=false` 保持 `camera.up` 始终为世界 +Y, 因此空格 / Ctrl 的升降稳定垂直。

### 4. 鼠标捕获与 rlImGui 光标管理的冲突处理

rlImGui 在 `rlImGuiBegin()`(内部 `ImGuiNewFrame`)中会根据 ImGui 期望的光标形状调用 raylib 的 `HideCursor()/ShowCursor()` 管理光标。若直接在相机更新阶段 `DisableCursor()`, 当鼠标划过文本框等会改变光标形状的控件时, rlImGui 会调用 `ShowCursor()` 把鼠标重新显示出来, 与捕获逻辑冲突。

处理方案: **在捕获鼠标期间临时置位 `io.ConfigFlags |= ImGuiConfigFlags_NoMouseCursorChange`**, 使 rlImGui 完全跳过光标管理, 由本功能独占光标控制权; 释放右键时清除该标志并 `EnableCursor()` 恢复正常。这样既不破坏 ImGui 平时的光标行为(仅旋转期间接管), 又能可靠隐藏鼠标。

> 注: `WantCaptureMouse` / `WantCaptureKeyboard` 在相机更新阶段读取的是上一帧 ImGui 计算的结果(相机更新在 `rlImGuiBegin` 之前执行), 与现有环绕控制的 `!ImGui::GetIO().WantCaptureMouse` 判断方式一致, 存在 1 帧延迟, 实际使用无感。

### 5. ImGui 面板变更(`相机` 折叠组)

```cpp
ImGui::Checkbox("鼠标环绕控制 (移动旋转 / 滚轮缩放)", &orbitalControl);
if (ImGui::Checkbox("手动操作 (WASD/空格/Ctrl 移动, 右键旋转)", &manualControl) && manualControl) {
    orbitalControl = false;   // 与环绕控制互斥
}

ImGui::BeginDisabled(!manualControl);
ImGui::SliderFloat("移动速度", &cameraMoveSpeed, 0.1f, 50.0f);
ImGui::SliderFloat("旋转速度", &cameraRotateSpeed, 0.0005f, 0.01f, "%.4f");
ImGui::EndDisabled();

ImGui::BeginDisabled(orbitalControl || manualControl);
// 位置 / 目标点 / Up / FOV / 投影 (与现状一致, 手动模式开启时同样禁用, 避免参数被覆盖)
ImGui::EndDisabled();
```

- 勾选「鼠标环绕控制」时, 同步关闭手动操作(在环绕 checkbox 的 `&& orbitalControl` 分支中置 `manualControl = false`), 保证二者互斥。
- 移动 / 旋转速度滑块仅在手动模式开启时生效, 关闭时置灰。
- 手动模式开启时与环绕一致, 禁用 `位置/目标点/Up/FOV/投影` 参数直调, 避免手动控制与手写参数互相覆盖。

### 6. 主循环接入

```cpp
if (orbitalControl && !ImGui::GetIO().WantCaptureMouse) {
    UpdateCamera(&camera, CAMERA_ORBITAL);
}
if (manualControl) {
    updateManualCamera(camera, cameraMoveSpeed, cameraRotateSpeed);
}
```

手动模式不依赖 `WantCaptureMouse` 整体关闭(移动用 `WantCaptureKeyboard`、旋转用 `WantCaptureMouse` 分别门控), 因此即便鼠标悬停在面板上, 只要未在文本输入状态, WASD 移动依然可用。

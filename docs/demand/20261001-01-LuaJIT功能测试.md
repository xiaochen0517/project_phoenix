## 需求背景

项目当前通过 vcpkg 的 `lua` 包集成的脚本引擎是 **PUC Lua**(5.4), 仅用于验证脚本链路(`script/lua_runner` 的一次性 `eval_string`)。为后续承载游戏脚本(热更新、高频逻辑、FFI 等), 需要验证 **LuaJIT** 作为脚本引擎的可行性:

- LuaJIT 是 Lua 5.1 API 的 JIT 实现, 热路径循环执行性能远超纯解释型 Lua。
- vcpkg 的 `luajit` port 采用官方仓库 `LuaJIT/LuaJIT` 的 master 分支(2.1 线), 当前 baseline 已固定到 `2026-09-08` 提交 `c6ffc141`, 即官方「最新版」LuaJIT。
- LuaJIT 的 C API 与 Lua 5.1 兼容, 现有 `lua_runner.cpp` 仅用到 `luaL_newstate / luaL_openlibs / luaL_dostring / lua_tostring / lua_close / LUA_OK`, 均在 LuaJIT 中有对应定义, 预计可无改动迁移。

## 需求目标

1. 用 vcpkg 的 `luajit` 包替换现有 `lua` 包, 完成 CMake 与代码接入。
2. 运行简单 Lua 脚本, 验证 LuaJIT 生效(版本号 + JIT 状态), 并观察 JIT 对热循环的加速效果。

## 设计方案

### 1. 依赖切换 (vcpkg)

`vcpkg.json` 的 `dependencies` 中 `"lua"` → `"luajit"`。`builtin-baseline` 不变(当前 baseline 已包含官方 LuaJIT 的 2026-09-08 提交)。

### 2. CMake 接入

vcpkg 的 `luajit` port **只导出 pkgconfig**(`luajit.pc`), 不提供 CMake config package; 其安装布局固定为:

- 头文件: `${VCPKG_INSTALLED_DIR}/<triplet>/include/luajit/`(`lua.hpp / lua.h / luaconf.h / lauxlib.h / lualib.h / luajit.h`)
- 静态库: `${VCPKG_INSTALLED_DIR}/<triplet>/lib/lua51.lib`(abiver=51)

因此不依赖 pkgconf 工具, 直接用 `find_path / find_library` 定位即可(顶层 `CMakeLists.txt`):

```cmake
# LuaJIT 由 vcpkg (manifest 模式) 提供, 安装布局固定为 include/luajit 与 lib/lua51。
find_path(LUAJIT_INCLUDE_DIR NAMES lua.hpp PATH_SUFFIXES luajit)
find_library(LUAJIT_LIBRARY NAMES lua51 liblua51)
if(NOT LUAJIT_INCLUDE_DIR OR NOT LUAJIT_LIBRARY)
    message(FATAL_ERROR "LuaJIT not found (expected vcpkg luajit port)")
endif()
```

原 `find_package(Lua REQUIRED)` 删除。

`core/CMakeLists.txt` 中 `${LUA_INCLUDE_DIR}` → `${LUAJIT_INCLUDE_DIR}`、`${LUA_LIBRARIES}` → `${LUAJIT_LIBRARY}`。

### 3. 代码接入

- `script/lua_runner.cpp`: 保留 `#include <lua.hpp>`(LuaJIT 在 `include/luajit/` 下提供同名头, 已被 include path 覆盖), 现有逻辑不变。
- `main.cpp` 启动自检脚本改为报告 LuaJIT 版本与 JIT 状态, 并跑一个热循环观察 JIT 效果:

```lua
local sum = 0
for i = 1, 1e7 do sum = sum + i end
return string.format('LuaJIT %s (Lua %s), sum=%d, jit.status=%s',
                     jit.version, _VERSION, sum, jit.status())
```

### 4. 文档变更

更新 `docs/项目架构文档.md`: 依赖表中 `Lua` 行改为 `LuaJIT`(来源、版本说明)、`6.2 script/` 与 `5.1` 中对应的 `find_package(Lua)` 描述、`7 关键架构决策` 补充 JIT 选型说明。

### 5. 验证方式

构建 `msvc-debug` 后运行程序, 观察日志输出:

1. `LuaJIT result: LuaJIT 2.1.0-beta3 (Lua 5.1), sum=50000005000000, jit.status=true`。
2. 程序窗口正常启动(确认 LuaJIT 静态库链接无冲突)。

## 确认结果 (2026-10-01)

1. LuaJIT 来源: 官方 `LuaJIT/LuaJIT`(vcpkg, 2026-09-08 提交)。
2. 测试脚本: 保留「1e7 热循环求和」。

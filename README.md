# project_phoenix

C++17 桌面游戏程序（技术验证阶段）。

## 构建

```
cmake --preset msvc-debug
cmake --build --preset msvc-debug
```

Windows 需在 "x64 Native Tools Command Prompt for VS" 中执行（或先运行 `vcvars64.bat`）；release 使用 `msvc-release`。Linux 使用 `linux-debug` / `linux-release`。

## 开发状态

本项目为测试学习项目，当前处于开发中，功能尚未完成。
